What you need

  • Node.js 22 or newer.
  • Git, to clone the repository.
  • A current browser.

There is no install step. Recipe Bank has no dependencies, so there is nothing for npm install to fetch, and there is no build step for local use.

Install and run

Terminal 
git clone https://github.com/axeltoll/recipe-bank.git
cd recipe-bank
npm start

Open http://127.0.0.1:4780. The repository comes with the author's own analyzed recipes, so the dashboard has something to show at once. Set the PORT and HOST environment variables to change the address.

The server listens on your own machine only and has no login. Read the note in the self-hosting guide before you change HOST.

Tour: the home page

The home page is the collection. It answers one question: what can I cook with what I have?

  1. Ingredients. Every ingredient in the collection is a chip with the number of recipes that use it. Pick one or more.
  2. Has all and Has any. Has all keeps the recipes that use every ingredient you picked. Has any keeps the recipes that use at least one.
  3. Search. Type a dish, a creator or an ingredient. Search and chips work together.
  4. Recipes. Each card shows the title, the creator and some of its ingredients. A partial recipe is labelled as partial.
  5. In the queue. Videos that wait for analysis are listed under the recipes. You can watch one there or remove it from the queue.

The dashboard remembers the filters you last used in your browser. That is a convenience, not data: clearing it loses nothing.

Tour: a recipe

  1. The video. The original video is embedded from its platform, with the creator credited and linked.
  2. Ingredients. A checklist, grouped by the parts of the dish. Each amount is in the creator's own words. Where the video did not give one, the list says amount not given.
  3. Copy shopping list. Copies the ingredients and their amounts as plain text.
  4. Step by step. Each step with a timestamp has a play from here button that starts the embedded video at that moment.
  5. Nutrition. Shown only when the creator states it, with where it was stated.
  6. What the video does not say. The gaps: a missing temperature, an unnamed cut, a method the creator kept back.

Being merged This is built and is being merged into the main branch. Until the merge lands, a fresh clone may not have it.

The note above is about the redesigned dashboard. It keeps everything in this tour and adds separate phone, tablet and desktop layouts, a theme switch, a cook mode that shows one step at a time in large type, and a printable recipe. The feature list says where each of those stands.

Tour: add a video

  1. Press Add video and paste a link to a YouTube video or Short, a TikTok or an Instagram Reel. You can add a note for whoever does the analysis.
  2. The video joins the queue. If it is already a recipe or already queued, the dashboard tells you instead of adding it twice.
  3. The recipe is written as one file in recipes/, by a coding agent that follows the Recipe Agent instructions or by you from the recipe format.
  4. Once the recipe file exists, the video leaves the queue and shows up as a recipe.

Other commands

CommandWhat it does
npm run devStarts the dashboard and restarts it when the server or the shared library changes.
npm run validateChecks every recipe file and the queue against the contract.
npm testRuns the tests on Node's built-in test runner.
npm run buildWrites a read-only static copy of the dashboard to dist/.
npm run sitePreviews this website from site/ at http://127.0.0.1:4790.
