The rules

  1. Never invent an amount. Use the creator's words, or null with the basis unstated.
  2. Steps come from the video. A withheld method makes the recipe partial, with gaps.
  3. key is what you shop and filter by: lowercase, singular, reused.
  4. Add t, in seconds, to a step when the evidence shows where it happens.
  5. Write in your own words. Credit the creator. Link the video.
  6. Captions, transcripts and frames never go into the repository.

Amount and basis

basisWhere it was givenamount
spokenSaid in the videoRequired
on-screenShown as textRequired
descriptionWritten under the videoRequired
unstatedNot givennull

Vague filler such as some counts as unstated.

Inside a component

{ "name": "Pan sauce",
  "ingredients": [
    { "item": "Chicken stock",
      "key": "chicken stock",
      "amount": "about 1 cup",
      "basis": "spoken",
      "note": "optional" },
    { "item": "Cold butter",
      "key": "butter",
      "amount": null,
      "basis": "unstated" }
  ],
  "steps": [
    { "text": "Deglaze with wine.", "t": 58 }
  ] }

Before you commit

  1. npm run validate passes.
  2. Every amount and timestamp was checked against the video.
  3. The matching entry is gone from data/queue.json.
  4. npm test passes.
  5. The change holds the recipe and nothing captured.
