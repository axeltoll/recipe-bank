Turn any recipe video into exact ingredients and steps.

Recipe Bank keeps the short cooking videos you save as structured recipes: the ingredients in the creator's own amounts, and steps whose timestamps jump to that moment in the video. Today it reads links from YouTube (including Shorts), TikTok and Instagram Reels, and it runs on your own machine.

How it works

From a saved video to a recipe you can cook.

  1. 1

    Paste the link

    Press Add video on the dashboard and paste a YouTube Short, TikTok or Instagram Reel. It joins the queue, with the title looked up for you when the platform offers it.

  2. 2

    The recipe gets written

    An analysis agent reads the video's captions, description and on-screen text and writes one recipe file: ingredients in the creator's own amounts, steps with timestamps, and a list of what the video does not say. A validator checks the file against the recipe contract.

  3. 3

    Cook from it

    Filter the collection by what is in the fridge, tick ingredients off as you go, tap a timestamp to play the video from that step, and copy the ingredients as a shopping list.

Good to know

The dashboard, the queue, the recipe contract and the validator are in the repository today. The agent's own instructions are not yet: packaging it as a Recipe Agent you host yourself is on the roadmap. Until then, the contract in CLAUDE.md is what a coding agent, or you, writes a recipe file from.

What it does

Built for the moment you actually cook.

  • Filter by ingredient

    Pick ingredients and switch between Has all and Has any, or search by dish or creator.

  • Cook from the video

    Each recipe embeds the original video. Every step has a play from here timestamp, and you can tick off ingredients as you go.

  • Shopping list

    Copy a recipe's ingredients as a shopping list, in the creator's amounts.

  • Honest amounts

    Amounts are the creator's own words. When a video does not say, the recipe says amount not given instead of guessing.

  • Queue new videos

    Paste a video link to add it to the queue for analysis.

  • Credit to the creator

    Every recipe links back to the creator and the original video. Videos are embedded from the platform, never re-hosted.

The rule

It never invents an amount.

An amount is the creator's own words, with a note of where it came from: said in the video, shown on screen or written in the description. If the video does not say, the recipe says so. If part of the method is missing, the recipe is marked partial and lists the gaps.

Open source and self-hosted

Open source. Runs on your machine.

The code and the recipe files are MIT licensed. There is nothing to install besides Node.js 22 or newer: no packages, no database, no account.

Run it 
git clone https://github.com/axeltoll/recipe-bank.git
cd recipe-bank
npm start

The dashboard opens at http://127.0.0.1:4780. Set PORT or HOST to change that.

Roadmap

What comes next. Planned, not shipped.

None of this exists yet. It is the author's own plan, roughly in order, and it can change.

  • Planned

    Week plan and one shopping list

    Pick several recipes for the week and get one shopping list, with the same ingredient merged and amounts kept in the creators' own words.

  • Planned

    More ways to filter

    A without filter next to Has all and Has any, tags such as air fryer or high protein as chips, and protein and calorie limits for recipes that state macros.

  • Planned

    A Recipe Agent you host yourself

    The video analysis packaged for the coding agent you already use: captions and description first, local speech-to-text as a fallback, keyframes for on-screen text.

  • Planned

    Household planning and budget

    An anonymous household profile that stays on the device, purchase amounts for everyone at the table, and a food budget with spend per meal.

  • Planned

    More platforms

    Facebook and Pinterest videos, X, and plain web pages with a video, with embeds where the platform offers them and a link otherwise.

  • Planned

    Recipe packs

    Export favourite recipes as a single file or link and import someone else's pack, with duplicates detected by video. No accounts and no server.

Questions

Before you clone it.

Is Recipe Bank free?

Yes. The code and the recipe files are MIT licensed. The videos belong to their creators; Recipe Bank only links to and embeds them.

Which videos does it work with?

Today: YouTube, including Shorts, TikTok and Instagram Reels. Facebook and Pinterest videos, X and plain web pages with a video are planned.

Does it re-host videos?

No. Videos are embedded from their platform, never re-hosted, and every recipe links back to the creator and the original video. Material captured for analysis, such as transcripts and frames, is kept out of the repository.

Where do the amounts come from?

From the video: what the creator says, shows on screen or writes in the description. Each amount records which one. Nothing is estimated.

What is a partial recipe?

A recipe where part of the method is missing. It lists what it lacks instead of filling the holes with generic cooking knowledge.

Can I add a recipe myself?

Yes. A recipe is one JSON file in recipes/, in the format documented in CLAUDE.md. Run npm run validate to check it. A form for adding and editing recipes in the dashboard is planned.

Is there an account or a hosted version?

There is no account and no sign-up. Recipe Bank runs on your machine. npm run build makes a read-only static copy you can host yourself; on that copy, Add video copies a request instead of queueing.

Does the dashboard work on a phone?

It has layouts for narrow screens. An installable version that works offline is planned.

What is it built with?

Node.js 22 and nothing else: a node:http server with a small JSON API, a dashboard in plain ES modules and CSS, and tests on the built-in test runner.
