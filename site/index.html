Turn any recipe video into exact ingredients and steps.

Recipe Bank keeps the short cooking videos you save as structured recipes: the ingredients in the creator's own amounts, and steps whose timestamps jump to that moment in the video. Today it reads links from YouTube (including Shorts), TikTok and Instagram Reels, and it runs on your own machine.

How it works

From a saved video to a recipe you can cook.

  1. 1

    Paste the link

    Press Add video on the dashboard and paste a YouTube Short, TikTok or Instagram Reel. It joins the queue, with the title looked up for you when the platform offers it.

  2. 2

    The recipe gets written

    A coding agent, or you, reads the video's captions, description and on-screen text and writes one recipe file: ingredients in the creator's own amounts, steps with timestamps, and a list of what the video does not say. A validator checks the file against the recipe contract.

  3. 3

    Cook from it

    Filter the collection by what is in the fridge, tick ingredients off as you go, tap a timestamp to play the video from that step, and copy the ingredients as a shopping list.

About step 2

The dashboard, the queue, the recipe contract and the validator need no agent and no account. The recipe file is written by the Recipe Agent, a set of instructions for the coding agent you already use, or by hand from the recipe format. Recipe Bank has no hosted analysis service.

The rule

It never invents an amount.

An amount is the creator's own words, with a note of where it came from: said in the video, shown on screen or written in the description. If the video does not say, the recipe says so. If part of the method is missing, the recipe is marked partial and lists the gaps.

Open source and self-hosted

Open source. Runs on your machine.

The code and the recipe files are MIT licensed. There is nothing to install besides Node.js 22 or newer: no packages, no database, no account.

Run it 
git clone https://github.com/axeltoll/recipe-bank.git
cd recipe-bank
npm start

The dashboard opens at http://127.0.0.1:4780. Set PORT or HOST to change that.

Questions

Before you clone it.

Is Recipe Bank free?

Yes. The code and the recipe files are MIT licensed. The videos belong to their creators; Recipe Bank only links to and embeds them.

Which videos does it work with?

Today the dashboard takes links from YouTube, including Shorts, TikTok and Instagram Reels. Support for more platforms is listed under Features with where it stands.

Does it re-host videos?

No. Videos are embedded from their platform, never re-hosted, and every recipe links back to the creator and the original video. Material captured for analysis, such as transcripts and frames, is kept out of the repository.

Where do the amounts come from?

From the video: what the creator says, shows on screen or writes in the description. Each amount records which one. Nothing is estimated.

What is a partial recipe?

A recipe where part of the method is missing. It lists what it lacks instead of filling the holes with generic cooking knowledge.

Who writes the recipe file?

A coding agent that follows the Recipe Agent instructions, or you. Recipe Bank does not call an AI service by itself. A recipe is one JSON file in recipes/ in the recipe format, and npm run validate checks it.

Is there an account or a hosted version?

There is no account and no sign-up. Recipe Bank runs on your machine. npm run build makes a read-only static copy you can host yourself; on that copy, Add video copies a request instead of queueing.

Does the dashboard work on a phone?

It has layouts for narrow screens. The redesigned dashboard and an installable offline version are listed under Features and Roadmap with where they stand.

What is it built with?

Node.js 22 and nothing else: a node:http server with a small JSON API, a dashboard in plain ES modules and CSS, and tests on the built-in test runner.

Does this website track me?

No. It has no analytics, no cookies and no web fonts. The one request to another host is the three.js library from jsDelivr for the animated mark at the top of this page, and it is skipped when you prefer reduced motion, when data saving is on and when WebGL is not available. Your theme choice is stored in your browser only.
